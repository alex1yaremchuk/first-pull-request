🧪 First Pull Request

This repository provides new users with a needed practice of making Pull Requests. It was reworked to incorporate property-based testing (PBT). It aspires to illustrate how PBT can help reveal subtle bugs in simple functions like addition.

Try entering different values and find some quirks of our add(a, b) function in either language. You can use this interface to try and find counterexamples where their behavior doesn't match a + b.
