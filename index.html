Contribution Flow

The project is intentionally small so the GitHub workflow is the main thing you learn.

Fork

Create your copy of the repository.

Branch

Use fix/short-name or docs/short-name.

Fix

Change one file for one issue.

Test

Run npm test and npm run lint.

Pull Request

Open a PR and let CI verify the task.
